## 1. 背景与目标

### 1.1 场景定义

本项目的应用场景是"醒睡周期"架构中的**梦境引擎**：大模型在离线巩固阶段，用世界模型生成反事实情景进行演练（做梦），并将演练场景复用为遗忘审计的试炼场。世界模型在该场景中承担四个职能：

1. **反事实生成**——从未发生过的情景中解题，淬炼元知识；
2. **遗忘审计试炼场**——生成"依赖某条知识"的测试场景，判定该知识是否已内化为能力（先梦后删）；
3. **判梦的对象**——其输出被验证器评估，决定演练成果能否写入参数；
4. **跳帧模拟**——梦必须短（幻觉有复利），要求直接模拟 t+Δt 而非逐帧推演。

### 1.2 目标

设计并实现满足上述场景的世界模型**基础架构 v2** 与**训练方案**，在现有玩具试验台（解析弹球，EvoWorldModel，224K–280K 参数）上完成验证，然后沿"物理仿真 → 游戏级 → 真实数据"的阶梯扩展。

- `check_claims.py` 快速集：**11/11 PASS**（16/16 checkpoint 加载、P2 事件头链六项、P3 四条）。

### 2.3 重要发现：P3 头条数字为伪影

`intention_track4.py` 的 −1.000"完美区分"经逐层核查不成立：

1. `IdenticalBalls.__init__` 先执行父类构造（随机生成 **3 个球**），后设置 `n=2`——覆盖静默失败，实验实际跑在 3 球随机场景上（实测 `sim.pos(0.1)` 返回 3 行坐标）；
2. 追踪循环中 `track["pos"]` 从不更新，预测帧算出即丢弃，两条"轨迹"实为常数序列；
3. 常数序列的 corrcoef 本应为 NaN，实测因两次调用 `pos(0.1)` 的 1e-14 级浮点噪声呈虚假反相关，输出 −1.000。

**教训**：`check_claims.py` 验证的是"输出文本可复现"，不能验证"数字有语义"。需要新增扰动核验纪律（见 4.3-D7）。

## 4. 设计提案

### 4.1 基础架构 v2（五项改动）

**A. 双结构状态：对象槽位 + 全局场。**
保留"3 帧 → 固定维状态 → Δt 原生演化"骨架，但状态从纯像素网格升级为双结构：对象槽位（数量 N 由顶层意图声明，感知证据按轨迹连续性分配）承载可对象化实体；全局场承载背景。反事实操作以槽位为单位（"如果那个球往左一点"）。——P3 概念的正确实现。

**B. 事件机制升为头等公民，带监督接地。**
事件头从只读探针改为训练时参与损失的事件分支：预测"下一事件类型 + 时间 + 载荷"，以解析真值监督。直接将 P2 的梯度对齐条件实现为损失函数，替代失败的事件门自举（P1 事件门仅降撞墙税 18%，负结果 N1 表明事件信号在像素损失中太弱）。

**C. 哈密顿流重新定位为正则化机制。**
其价值是守恒约束防状态雪崩，而非精度机制（2.0s 相位仍崩）。相位精度的正解在事件分支，不在积分器。

**D. 动作/干预条件化作为一等输入。**
s(t), a, Δt ↦ s(t+Δt)。动作与 Δt 并列进入演化算子，从"观测的世界模型"升级为"可用的世界模型"（v11 act_eval 已开端）。

**E. 探针层制度化。**
冻结流 + 只读探针从训练技巧升级为架构纪律：一切读取走探针，一切写入走巩固（依据：联合训练使像素任务退化 42%，冻结零干扰）。

### 4.2 训练方案（四条原则）

**T1 多信号课程。**
被动预测打底 → 事件监督（被教）→ 动作条件任务奖励（死于/功能性压力）→ 多智能体互相预测（被懂）。mini21 的 5/5 种子支持第三路径，应升级为正式训练阶段。

**T2 梯度对齐作为损失设计原则。**
时间加权损失：权重由事件头不确定性自适应生成，事件附近梯度自动放大。替代手工前景权重（×20）。

**T3 语义核验先行。**
每个 headline 数字配扰动对照组（改球数/初速/种子，数字应按预期方式变化；恒为定值或剧烈波动即报警）。

**T4 多种子分级制。**
探索可单种子，入表数字 5 种子起。

### 4.3 方法学纪律（新增）

- **D7 扰动核验**：claim check 不只比对输出文本，必须内置扰动测试。（源自 −1.000 伪影事件）
- 沿用 D6：发表前从发布产物重生成每个数字。

## 附录 A：可用原理库

本附录汇总本项目可直接依据的原理。每条注明来源、证据强度，以及在世界模型研发中的具体用法。证据强度分三级：**【实证】**有直接实验支持；**【理论】**有公认理论或广泛间接证据；**【启发】**是启发式表述，待用本项目检验。

### A.1 记忆与遗忘原理（醒睡周期讨论沉淀）

| # | 原理 | 来源与强度 | 对本项目的用法 |
|---|---|---|---|
| A1 | **三难权衡**：密度、泛化、可寻址三者不可兼得；纯参数架构放弃可寻址 | superposition 研究（Toy Models of Superposition）；unlearning 实证（relearning 复活、纠缠度因果测量）【实证】 | 世界模型的状态设计要在三角中显式选位：显式固定维状态（R2）本身就是用密度换可寻址（可拷贝、可回退、可探针） |
| A2 | **遗忘是默认，记住需审批**：默认衰减 + 选择性巩固，优于全量存储 + 事后删除 | 互补学习系统理论；grokking 中 weight decay 磨掉无梯度支持的记忆权重【实证】 | 训练方案 T2 的时间加权损失即"审批"机制；也提示世界模型自身应带衰减压力，防止状态场无限膨胀 |
| A3 | **元知识是取平均后的幸存者**：打乱交错的重复中，变化的互相抵消、不变的沉淀 | 睡眠回放的神经机制；grokking 复刻【实证】 | 做梦阶段的采样策略：同一因果结构、多种表皮伪装（受控变量），主动制造"取平均"条件而非依赖语料偶然性 |
| A4 | **素材销毁，蒸馏物全留**：婴儿期遗忘删除情景碎片、保留技能与语义 | 婴儿期遗忘研究（神经发生、突触修剪）【实证】 | 重生蒸馏（阶段四）的生物依据；也提示评估指标要区分"情景保真"与"结构保真" |
| A5 | **保真动力学 + 打乱素材 = 梦**：梦的真实感来自世界模型的动力学约束，荒诞感来自素材重组 | REM 梦研究；威胁模拟理论【理论】 | 反事实生成器的构造公式：不需要生成新世界，只需够好的世界模型 + 敢打乱的采样器 |
| A6 | **幻觉有复利**：多步模拟误差逐层累积，梦必须短、必须频繁用真实数据校准 | model collapse（Shumailov et al., Nature 2024）；P1 可预测视界 ~1.5s【实证】 | 跳帧模拟的步长上限由可预测视界决定；世界模型要内置"视界估计"探针，超出视界的梦境降权或截断 |
| A7 | **模拟不能注入关于真实世界的新信息** | 信息论【理论】 | 明确做梦的功能边界：重组、压榨、巩固已有认知；新信息只能来自真实交互。研发评估不应期待梦境提升"世界知识"，只应期待提升"结构化能力" |
| A8 | **先梦后删**：遗忘审计 = 世界模型生成依赖某知识的场景，移除后仍能解题 ⇒ 知识已内化 | 醒睡周期架构推导【启发】 | 阶段四核心实验的设计蓝本 |
| A9 | **技能即结构化的领域知识**：专家的"纯推理"远少于想象，技能载体是大量内化模式 | Chase & Simon 象棋实验（1973）【实证】 | 审计"知识已内化"时，判据应是该知识领域的模式化表现，而非通用推理指标 |

| B6 | **可预测视界有限且可测**：技能分随 Δt 衰减，存在明确视界（~1.5s） | P1 §5.3【实证，玩具尺度】 | 梦长上限的量化工具；每个新试验台首先测视界 |

| B8 | **残差惊讶度不足以驱动事件分割**（负结果 N1）：预测残差测的是"模型的失败"，成功的事件架构反而抹掉残差 | P1 surprise_eval【实证，玩具尺度】 | 不要指望用预测误差自动发现事件；事件信号需要显式化 |
